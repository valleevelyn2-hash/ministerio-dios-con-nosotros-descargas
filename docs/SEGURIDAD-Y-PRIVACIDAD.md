# Seguridad y privacidad

- Este repositorio es público y debe contener solamente información y archivos destinados a distribución pública.
- El repositorio privado conserva el código fuente y la configuración interna de compilación.
- Las contraseñas, tokens y claves privadas nunca se guardan en este repositorio ni dentro del APK.
- La clave de firma se conserva bajo control seguro y con respaldo protegido.
- Los archivos de descarga deben distribuirse por HTTPS.
- El SHA-256 ayuda a detectar archivos alterados; la firma Android permite comprobar la identidad del firmante.
- No se deben incluir datos personales, pedidos de oración, testimonios privados ni información de miembros.
- La aplicación debe solicitar confirmación antes de acciones sensibles y respetar los permisos del usuario.

Si se detecta una publicación incorrecta, se debe detener la distribución, corregir el manifiesto y registrar el incidente sin borrar el historial de versiones.
